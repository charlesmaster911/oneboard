# 팀업무·회의록 인터랙티브 복원 사양

## 목표

OneBoard의 팀업무와 회의록을 긴 원문 목록이 아닌 읽을 수 있는 운영 화면으로 복원하고, owner/ops가 같은 화면에서 신규 입력·수정·삭제할 수 있게 한다.

## 팀업무

- 기존 화면처럼 상단에 통합·담당자별 탭을 표시하고, 탭 선택에 따라 업무를 필터링한다.
- 왼쪽에는 이번 달 미완료 우선순위 업무, 가운데에는 6주 월간 캘린더, 오른쪽에는 최근 회의록과 지연 업무 알림을 표시한다.
- 캘린더에서 날짜 이동·오늘 복귀·업무 추가가 가능하고, 업무 카드를 누르면 기존 업무 모달이 열린다.
- owner/ops는 업무 전체 필드를 입력·수정·삭제하고, 배정된 member/marketing은 기존 역할 규칙 안에서 상태와 메모를 수정한다.
- 캘린더 범례와 담당자 색상은 실제 API 데이터에서 동적으로 만든다.
- 긴 ISO 날짜는 `2026. 09. 02. (수)` 형태로 표시한다.

## 회의록

- 데스크톱은 왼쪽 목록과 오른쪽 상세의 2단 구조, 모바일은 목록 다음 상세 구조로 표시한다.
- 목록에서 날짜·제목·요약을 확인하고 검색할 수 있다.
- 상세에서 참석자, 요약, 지시사항, 본문, 데이터 출처를 읽는다.
- owner/ops는 새 회의록 작성, 기존 회의록 수정·삭제를 할 수 있다.
- 입력 필드는 날짜, 제목, 참석자, 요약, 지시사항, 주요 논의 내용이다.

## 저장·동기화 안전성

- OneBoard에서 만든 항목은 로컬 운영 데이터로 저장한다.
- 구글시트에서 가져온 항목을 OneBoard에서 수정하면 `manual_override`로 표시해 이후 오전 9시 동기화가 덮어쓰지 않는다.
- 삭제는 소프트 삭제하여 구글시트 동기화가 다음 날 같은 항목을 되살리지 못하게 한다.
- 조회와 내보내기는 삭제되지 않은 항목만 포함한다.

## 완료 기준

- 프런트·백엔드 자동 테스트가 모두 통과한다.
- 실제 배포 주소에서 업무와 회의록이 읽을 수 있는 형태로 보인다.
- 실제 배포 주소에서 테스트 항목 생성, 새로고침 후 유지, 수정 후 유지, 삭제가 확인된다.
- 390px 모바일 폭에서도 패널과 회의록 상세를 사용할 수 있고, 월간 캘린더는 패널 안에서 가로 스크롤할 수 있다.
